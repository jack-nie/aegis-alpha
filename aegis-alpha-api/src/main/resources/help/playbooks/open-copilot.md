# 如何打开 AI Copilot

1. 登录 Aegis Alpha 控制台。
2. 点击顶部导航栏的 **AI Copilot** 图标（Header 右侧）。
3. 右侧（或侧栏）会打开对话面板。
4. 可直接输入研究问题（如「深度分析 AAPL」）或产品问题（如「什么是 DEGRADED」）。

## 提示

- 在 **运行详情 / 推荐详情** 页打开助手时，会自动带上页面上下文（runId 等），便于诊断。
- 研究类问题可能自动路由到 published 工作流，并在运行中心跟踪进度。
