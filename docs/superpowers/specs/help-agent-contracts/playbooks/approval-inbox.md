# 推荐审批在哪里做

1. 进入 **推荐 / 审批收件箱**（Recommendations Inbox）。
2. 筛选状态为 `PENDING_REVIEW` 的条目。
3. 打开详情，核对：
   - 推荐标签与摘要
   - **证据（evidence）** 列表
   - 是否标记 degraded / 数据不足
4. 人工选择 **批准** 或 **驳回**。

## 重要

- **助手不能代为审批**。任何「帮我批准」请求只会引导你到此页面。
- 证据不足或 degraded 时，请优先补数据或重跑研究工作流。
